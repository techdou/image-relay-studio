# 合规边界文档

## 核心原则

本项目严格遵守以下合规边界：

### 1. 仅使用扣子官方公开支持的能力

**允许使用**:
- coze-coding-dev-sdk 中当前项目实际可用的服务端能力
- 扣子官方发布的 Workflow API
- 扣子官方 OpenAPI
- 扣子官方 Bot、Workflow 或 Plugin Runner
- 项目环境自动注入的官方环境变量
- 官方对象存储、数据库和认证能力

**严禁使用**:
- 抓取扣子网页接口
- 使用浏览器 Cookie、Session、LocalStorage Token 调用模型
- 模拟网页点击或浏览器自动化生成图片
- 调用未公开私有接口
- 逆向接口签名
- 绕过调用额度、并发限制或账号限制

### 2. 不共享扣子账号

- 每个内部用户使用自己的认证身份
- 不共享扣子 Token
- 不向用户暴露扣子凭证

### 3. 不转售调用权益

- 平台不开放付费
- 不提供套餐购买
- 仅为内部白名单用户使用

### 4. 不绕过限流

- 尊重平台并发限制
- 实现用户端速率限制
- 不使用多账号轮换绕过限制

### 5. 不删除隐式 AI 标识

- 当且仅当官方 SDK/工作流明确支持时，才关闭画面可见水印
- 不得清除平台附加的隐式 AI 标识
- 不得修改生成文件以伪装为真人创作
- 不得删除依法必须保留的生成标识

### 6. 产品界面保留 AI 生成说明

- 每张图片显示"本内容由人工智能生成"
- 图片详情记录生成模型、时间、参数等
- 下载不烧录提示文字到像素，但数据库保留 AI 生成属性

### 7. 项目不宣传为扣子模型代理

- 项目定位为内部 AI 图像生成平台
- 不对外宣传与扣子的关系
- 不声称兼容任何第三方 API

## 安全检查

项目必须能通过正常的平台安全检查：

- 所有模型调用在服务端
- 经过用户身份验证
- 经过权限验证
- 经过额度验证
- 经过参数验证
- 经过速率限制
- 写入使用记录
- 写入审计信息
- 支持管理员立即关闭服务
